# Vindhem Server

**WIP**

Vindhem Server is the planned standalone implementation of the
[Vindhem specification](https://github.com/Hallmane/vindhem). It is intended to
provide a core library engine, command-line interface, and generic MCP adapter
for local-first music library management.

## Status

WIP

This repository currently contains documentation only.
The engine, CLI, and generic MCP adapter have not been extracted into this
repository, and no runtime package or installable release is available yet.

The planned server will keep library data under user control, preserve original
music files during import, and expose the same core capabilities through CLI and
MCP interfaces. These are project goals, not claims about currently released
code.
